# DeskWeek Android 功能测试与体验指南

本指南旨在帮助大家快速上手体验 DeskWeek Android 客户端的各项核心功能，并提供常用的功能测试场景。

---

## 准备工作

- **测试设备**：Android 手机或平板（系统支持 Android 8.0 及以上）。
- **安装软件**：下载并安装最新的 DeskWeek 安装包（APK）。
- **网络环境**：如需体验局域网设备发现与协同，建议手机与电脑连接到同一个 Wi-Fi 网络。

---

## 一、核心功能体验

### 1. 任务创建与基本管理
- **新建待办**：在主界面点击底部的输入框，输入任务标题（例如“周三下午两点开会”），选择所属日期和具体时间，点击“添加”。
- **任务编辑**：点击任意任务卡片进入编辑模式，可修改标题、补充详细备忘录，或者调整提前显示规则。
- **任务完成**：点击任务前方的圆形复选框，任务将被标记为完成，并伴随划线样式移至已完成区域；再次点击可撤销完成。
- **废纸篓与恢复**：在任务详情中选择“移入废纸篓”，已删除任务可在左侧菜单的“废纸篓”中查看，并支持一键恢复或彻底删除。

### 2. 长按拖拽与灵活改期
- **长按拖拽改期**：长按一条任务并拖动，会跟随显示当前拖动任务的悬浮标签，将其拖拽并松手到其他星期几的日期格内，任务即可快速调整到新日期。
- **弹窗快速改期**：也可以长按任务弹出日期选择对话框，直接选择目标日期完成改期。

### 3. 农历、节气与节假日查看
- 在周历视图上方可以看到当天的公历日期、农历日期（如“冬月初一”）。
- 遇到传统节气（如“冬至”、“立春”）或法定节假日（如“元旦”、“国庆”）时，界面会自动标注对应的节气名称与节假日标签。

## 二、桌面小组件（Widget）体验

DeskWeek 的一大特色是轻量、纯粹的桌面周历小组件，无需频繁进入 App 即可掌控日程。

### 1. 添加小组件到桌面
1. 长按手机桌面空白处，选择 **“微件” / “小组件”**（Widgets）。
2. 在列表中找到 **DeskWeek**，将其拖动添加到桌面上。
3. 可以在桌面上长按小组件并拖动边缘边框，自由调整小组件的显示大小（支持大、中、小多种尺寸）。

### 2. 小组件外观定制（透明底板与文字明暗）
- 在 App 的“设置”中，可以自由选择小组件的背景风格：
  - **全透明模式**：消除底板，文字直接悬浮在桌面壁纸上，极简美观。
  - **半透明/底板模式**：自带柔和底板，适合画面复杂的桌面壁纸。
  - **浅色/深色文字**：针对浅色或深色壁纸，随心切换文字颜色，保证清晰阅读。

### 3. 小组件直接交互
- 在桌面小组件上直接点击任务前面的勾选圆圈，可以直接完成该任务，无需跳转打开 App。
- 在 App 内新增或修改任务后，返回桌面即可看到小组件内容已自动更新。

## 三、数据安全与电脑端导入导出

所有日程默认保存在本地设备中，支持与 Windows 桌面版自由互通。

### 1. 导出备份
- 打开侧边栏菜单，选择 **“导出数据”**。
- 系统会弹出系统文件保存窗口，选择一个文件夹即可将当前所有日程导出为一个标准的 `data.json` 文件。

### 2. 从电脑端导入
- 将 Windows 电脑版 DeskWeek 的 `data.json` 文件传输到手机上（通过微信、QQ、网盘或 USB 拷贝均可）。
- 打开侧边栏选择 **“导入数据”**，选择该文件。
- App 会弹出提示框，支持选择：
  - **合并导入**：将文件中的任务与手机当前的任务合并，两边日程都保留。
  - **替换导入**：用文件中的内容完全替换当前数据（会自动归档原有的本地数据作为安全保护）。

### 3. 数据防损坏保护
- 如果在导入时误选了格式错误的无效文件，App 会自动提示格式不符并拒绝导入，绝不会导致现有日程被清空或损坏。

## 四、可选 AI 智能待办提取体验

如果你有一长段会议纪要、工作邮件或杂乱的日程草稿，可以使用 AI 功能一键提取为结构化待办。

### 1. 配置 API Key
- 打开侧边栏进入“设置”中的 **“AI 助手设置”**。
- 输入兼容 OpenAI 标准的接口地址（例如 `https://api.openai.com/v1`）、模型名称（例如 `gpt-4o-mini`）以及你的 API Key。
- 点击“保存”，系统会通过 Android Keystore 安全芯片对密钥进行加密存储。

### 2. 智能提取与一键入库
- 进入 AI 提取页面，在文本框中粘贴一段包含日程安排的文字（例如：“下周二上午10点参加部门例会，周四下午提交周报”）。
- 点击 **“智能提取待办”**。
- AI 分析完成后会列出解析出的多条任务草稿，包含提取出的标题和对应日期。
- 确认无误后点击 **“一键批量添加”**，所有提取出的事项会自动加入到你的待办清单和周历中。

## 五、局域网设备互联体验（持续迭代中）

DeskWeek 正在开发局域网多设备协同功能，实现手机、平板与 Windows 电脑在同一个局域网内的直接通信。

### 体验步骤：
1. 确保手机与电脑连接在同一个 Wi-Fi 网络下。
2. 在手机 App 的“设置”中找到 **“局域网同步”** 区域，点击 **“搜索设备”**。
3. 系统会通过局域网 mDNS 自动搜索同网络下正在运行的 DeskWeek 电脑端或平板设备。
4. 搜索到目标设备后，会自动填入该设备的主机地址与端口。
5. 后续版本将持续完善跨设备自动增量同步与免密互通体验。
