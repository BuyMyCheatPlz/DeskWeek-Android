# DeskWeek Android 客户端规划与架构设计

本文档介绍了 DeskWeek Android 客户端的产品定位、界面设计、核心技术架构以及多端协同的发展规划。

---

## 一、产品定位与核心理念

DeskWeek 诞生于 Windows 桌面，以“直接贴合在桌面背景上、周历一览无余、本地存储安全纯粹”而受到用户喜爱。

在 Android 端，我们延续这一核心理念：
1. **轻量与融入桌面**：通过精美的**全透明桌面周历小组件**，让用户无需点开 App，在手机桌面上就能像电脑桌面一样直接查看日程并打勾完成。
2. **本地优先与隐私保护**：所有待办日程保存在用户设备本地，不强制注册账号，不依赖第三方云端，打开即用、快速无广告。
3. **多设备局域网无感协同**：在同一个局域网（如家里的 Wi-Fi）中，手机、平板与 Windows 电脑可互相发现并直接同步改动，电脑关机时手机和平板也能彼此互通。
4. **统一多尺寸设备适配**：一个安装包同时适配手机、折叠屏与平板大屏，自动根据屏幕宽度呈现最佳布局。

---

## 二、界面设计与尺寸适配

应用采用现代化的 Android 原生技术栈（Kotlin + Jetpack Compose + Material 3），并针对不同设备尺寸做到了自适应布局：

### 1. 手机与小屏幕设备
- **周历展示**：顶部展示七日横向日期条，突出显示当前周与选中的日期；下方直观展示当日待办事项与未分类事项。
- **单手操作优化**：新增输入框与核心功能常驻底部，任务编辑支持底部半屏抽屉式展开，单手录入顺畅自然。

### 2. 平板与宽屏设备
- **七列完整周历**：在大屏幕宽度下，自动展开为类似电脑端的完整七列周历视图，整周安排一目了然。
- **分栏布局**：左侧为导航与日历概览，右侧为任务详情与快速编辑区，充分利用宽屏显示空间。

### 3. 桌面小组件（App Widget）
基于 Android Glance 技术开发，提供多种尺寸的自适应排版：
- **小尺寸**：展示今日核心待办与快捷新增入口。
- **中尺寸**：展示近期日程与勾选打卡。
- **大尺寸**：展开为完整的桌面周历卡片。
- **外观支持**：提供“标准底板”与“全透明”两种风格，并支持根据手机壁纸深浅自由调整文字颜色。

## 三、核心功能模块

| 功能模块 | 设计说明 |
| --- | --- |
| **任务日常管理** | 支持添加标题、补充详细备忘、设置特定时间、完成打勾与撤销；支持废纸篓机制与一键恢复。 |
| **提前提醒规则** | 任务可设置提前数天或提前一个月在待办中出现，重要事情提前筹划，日历视图中始终可查。 |
| **拖拽与弹窗改期** | 支持长按任务直接拖拽至目标日期列，也支持长按弹出日期弹窗快速修改所属日期。 |
| **农历与节假日** | 内置离线农历与二十四节气转换，标注法定公休节日，方便安排工作与传统生活日程。 |
| **可选 AI 智能提取** | 支持长段文本智能解析为多条待办，API 密钥使用系统 Android Keystore 硬件级加密存储。 |
| **数据备份与交换** | 支持导出标准 `data.json` 文件，并与 Windows 电脑版无缝导入互通；保存时自动保留有效备份。 |

## 四、局域网多设备协同机制

DeskWeek 采用**去中心化的局域网点对点通信架构**，不设置中心服务器：

1. **自动发现**：在局域网内通过标准 mDNS / DNS-SD 广播（服务标识 `_deskweek-sync._tcp`），设备上线后自动发现同一局域网下的其他 DeskWeek 设备。
2. **端到端加密通信**：设备之间通过 TLS 安全加密通道连接，配对时交换证书指纹，保障数据传输过程安全防窃听。
3. **增量操作与离线合并**：
   - 每次任务的添加、修改、完成都作为一条带有时间因果的操作记录在本地。
   - 当设备重新接入局域网时，彼此交换彼此缺失的操作日志。
   - 如果遇到在不同设备上同时修改了同一条任务，系统会自动合并不同字段的改动，遇到直接文字冲突时保留双方候选供用户确认，绝不丢弃任何内容。
4. **电脑离线不影响移动端**：手机与平板之间是对等关系，即使电脑关机，手机和平板在家里也能独立完成同步。

## 五、技术分层与工程结构

- `com.deskweek.android.ui`：Compose 界面层，包含手机/平板自适应页面、主题切换与各功能弹窗。
- `com.deskweek.android.widget`：Glance 桌面小组件实现，负责小组件布局渲染、桌面快捷操作与即时刷新。
- `com.deskweek.android.core.data`：本地数据存储仓库（TaskRepository、TaskStore），负责数据原子写入、自动备份、冲突解决与导入导出。
- `com.deskweek.android.core.model`：核心数据模型与业务规则（Task、TaskRules、日期工具）。
- `com.deskweek.android.core.ai`：AI 接口客户端与 Android Keystore 密钥安全管理。
- `com.deskweek.android.core.sync`：局域网发现（NsdDiscovery）、TLS 协议会话（SyncSession）、日志持久化与增量合并逻辑。

## 六、未来路线图

1. **多端局域网同步体验打磨**：提供更便捷的扫码配对向导与同步状态面板。
2. **更多视图支持**：增加月视图与年视图，满足中长期规划需求。
3. **桌面小组件微动效与个性化**：持续提升小组件在各大手机厂商 Launcher 上的兼容性与美观度。
