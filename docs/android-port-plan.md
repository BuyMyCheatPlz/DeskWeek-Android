# DeskWeek Android 与三端同步规划

> 2026-11-10：跨端传输方案已改为 [二维码与文件离线传输](offline-json-qr.md)。下面的局域网自动同步是历史设计，暂未实现。

## 1. 产品方向

三台设备（Windows 电脑、Android 手机、Android 平板）各自保存完整的任务数据，断网也能独立使用。第一次配对后，只要在同一个局域网里就能自动发现对方、互相同步改动。不需要账号、不需要云服务、不需要固定某台设备当服务器。电脑关了手机和平板也能直接同步。

Android 的主要形态是**透明桌面周历小组件 + 完整管理 App**，保留你原来的壁纸，和 Wallpaper Engine 等动态壁纸可以共存。

| 项目 | 方案 |
| --- | --- |
| 安装包 | 手机和平板共用一个 APK，自动适配屏幕大小 |
| 桌面展示 | 周历小组件，可调透明度和尺寸 |
| 数据 | 本地优先，三端对等同步 |
| 配对 | 第一次逐对确认（扫码或核对数字），之后自动连接 |
| 外观 | 沿用桌面版的配色和主题 |
| 第一版 | 任务管理、周视图、小组件、局域网同步、备份、导入导出 |
| 后续 | 年/月/日视图、AI 功能增强等 |

> "同一网络就能同步"的前提是完成了首次配对、相关权限已开启。不会自动信任同网络的陌生设备。手机被系统后台杀掉后不保证立即同步，恢复运行后会自动补齐。

## 2. 桌面版源码

| 工程 | 本地目录 | 同步结果 |
| --- | --- | --- |
| Windows | C:\Users\Enjory Wong\Deskweek | 已拉取最新代码 |
| Android | C:\Users\Enjory Wong\DeskWeek-Android | 已是最新 |

桌面版是 Electron + Win32，版本号 1.3.0。桌面版的数据读写模块已经有冲突检查和原子写入，但这只解决同一台电脑多窗口的问题，还没有跨设备同步。

## 3. 手机和平板的布局

| 场景 | 手机（窄屏） | 平板（宽屏） |
| --- | --- | --- |
| App 周历 | 日期条 + 选中天的任务 | 七列完整周历 |
| App 导航 | 底部导航栏 | 侧边导航栏 |
| 小组件（小） | 今天的任务摘要 | 同样按实际大小显示 |
| 小组件（中） | 一周日期条 + 当天任务 | 三天或一周摘要 |
| 小组件（大） | 七天上下分区 | 七列完整周历 |

根据屏幕的实际宽度（dp）和字号缩放来布局，不是按手机型号判断。任务太多时显示"还有 N 项"，不会无限缩小字号。

小组件支持：点日期切换、一键完成任务、翻周、快速新建、打开详情。

## 4. 数据规则

- 第一版支持：新建、编辑、完成/撤销、删除到垃圾箱、恢复、永久删除
- 标题最多 100 字，备注最多 4000 字
- 提前显示支持"不提前""提前 1 个月""提前 N 天"
- 日期和时间表示日历上的本地时间，不会因为时区变化而自动平移
- 不认识的字段（比如桌面版新增的字段）会保留下来，导入导出不会丢掉
- 同步的内容包括任务、完成状态、垃圾箱；主题、密钥等个人设置留在各自设备上

## 5. 自动发现与后台限制

用 mDNS 在局域网里自动发现对方设备。如果 mDNS 不好用，也可以手动填 IP 或扫二维码。

| 设备状态 | 同步策略 |
| --- | --- |
| 电脑正在运行 | 随时可以发现和同步 |
| Android 在前台 | 自动发现、连接、交换数据 |
| 编辑任务或点小组件 | 先存本地，再尝试短时同步 |
| 网络恢复 | 自动重连并补齐 |
| Android 在后台 | 系统会安排定时补同步，但可能延迟 |
| 主动开启同步 | 会显示通知，超时后自动停止 |
| 系统省电 / 强行停止 | 不保证实时同步，恢复运行后补齐 |

> **Android 的后台限制**意味着：两台都在后台的手机和平板不一定能同时醒来同步。要想即时验证同步效果，请让两端都在前台。

## 6. 技术选型

| 层次 | 方向 |
| --- | --- |
| 界面 | Kotlin + Compose + Material 3 |
| 小组件 | Glance，大小自适应 |
| 数据 | Room 存任务和同步状态 |
| 同步协议 | 操作日志，按因果关系合并 |
| 传输 | 标准 TLS 加密连接 |
| 密钥 | Android 用 Keystore，Windows 用系统凭据 |

## 7. 导入导出

| 操作 | 规则 |
| --- | --- |
| 导出 data.json | 只包含任务数据，不包含密钥或配对信息 |
| 合并导入 | 先预览，同 ID 的用导入内容覆盖 |
| 覆盖导入 | 先备份，然后完全替换，会同步到其他设备 |
| 新建数据集 | 使用新的组，需要重新配对 |
| 完整备份 | 单独的格式，包含历史记录 |

## 8. 开发计划

| 阶段 | 做什么 | 怎么算通过 |
| --- | --- | --- |
| P0 基础验证 | 小组件、壁纸共存、两端加密通信 | 截图和通信记录齐全 |
| P1 本地功能 | 数据库、编辑、导入导出 | 重启不丢任务 |
| P2 同步正确性 | 操作日志、冲突、断线恢复 | 各种异常场景测试通过 |
| P3 自动连接 | 配对向导、自动发现、重连 | 任意两端能同步 |
| P4 界面完善 | 响应式布局、小组件交互 | 横竖屏、大字号通过 |
| P5 发布准备 | APK 签名、升级、权限处理 | 安装升级可恢复 |
