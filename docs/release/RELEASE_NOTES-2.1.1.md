## ✨ 新增功能与体验升级

**桌面小组件显示与排版重构**

- **高度与字号自适应**：综合考虑小组件的实际宽度、高度及系统字号缩放比例。针对较矮的桌面网格专门定制紧凑单行与微型字号布局，彻底解决部分桌面网格下任务标题被遮挡或高度变为零的问题，确保标题始终第一行清晰可见。
- **多日期任务智能摘要**：小号与中号组件按「今天事项 → 未排期事项 → 本周其他日期事项」智能呈现，跨日期任务附带直观的月/日标签（如 `11/12 · 事项`）。
- **透明背景与浅色文字即时更新**：修复在设置中切换透明背景或文字深浅后桌面小组件未实时跟随配色的问题，开关切换即刻动态响应。
- **高度预算与数量提示**：任务较多时根据可用高度自动计算最佳行数，超出部分以优雅的“还有 N 项”提示呈现，点击直达 App。

**二维码离线传输体验**

- 持续优化无损压缩传输体验，自动选用张数最少方案，面对面传输更省心。

## 🛠️ 稳定性与代码优化

- 完善了桌面小组件在系统后台的唤醒与数据更新机制。
- 进一步通俗化说明文档，消除技术黑话与专业用语。
