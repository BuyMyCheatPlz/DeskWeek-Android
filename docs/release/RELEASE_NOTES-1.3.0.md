# DeskWeek Android v1.3.0 · 全透明桌面小组件与体验升级

DeskWeek Android 客户端迎来重磅更新！本次更新带来了期待已久的**桌面周历全透明小组件**、更加顺手的**长按拖拽改期**、**农历与节气标注**、**AI 智能待办提取**，以及更完备的数据安全与跨端互通能力，同时对全部文档进行了通俗化重写。

---

### ✨ 新增功能与体验升级

- **桌面周历全透明小组件**
  - **全透明背景**：在 App 设置中开启“透明小组件”后，小组件将移除卡片底板，周历文字直接通透浮于壁纸之上，极简美观，不遮挡壁纸画面。
  - **深浅文字适配**：支持自由选择浅色（深色文字）或深色（浅色文字）主题，无论是清爽的浅色壁纸还是深色酷炫壁纸都能清晰阅读。
  - **桌面直接打勾完成**：在小组件上直接点击任务前面的勾选框即可完成待办，无需频繁进入 App。
  - **实时响应刷新**：App 内增删改任务后，返回桌面小组件即刻同步刷新。

- **任务长按拖拽改期与跨周交互**
  - **拖拽改期**：长按任务直接拖动到目标日期列松手即可完成改期，带有清晰的半透明悬浮跟随标签。
  - **双轨改期**：同时保留长按弹出日期选择器的方式，满足不同的操作习惯。
  - **跨周导航**：支持前后流畅翻周，并提供“回到今天”快捷按钮。

- **农历、节气与法定节假日**
  - 顶部日期栏新增农历日期对照（如“冬月初一”）。
  - 智能标注二十四节气（如“冬至”、“立春”）以及法定公休假日标签。

- **可选 AI 智能待办提取**
  - 支持输入整段会议纪要、工作邮件或备忘随笔，AI 自动为你提炼拆解出结构清晰的待办事项。
  - 提取结果支持预览并一键批量添加。
  - API 密钥由 Android 系统内置安全芯片（Android Keystore + AES-GCM）硬件级加密存储，安心保障凭证安全。

- **局域网设备发现（mDNS）**
  - 在局域网（同一 Wi-Fi）下支持自动搜索正在运行的 DeskWeek Windows 电脑端或平板设备，自动填充连接端点，为后续无缝同步奠定基础。

---

### 🛡️ 数据安全与稳定性修复

- **数据导入校验防护**：修复了旧版本导入空文件可能误清空现有日程的隐患；新增任务结构完整性校验，非法文件自动拒绝导入，原数据完好无损。
- **并发写入保护**：底层数据提交串行化，结合写入临时文件后安全重命名的机制，并自动留存有效备份，彻底避免保存冲突与异常丢失。
- **多端格式兼容**：完全兼容 Windows 桌面版的 `data.json` 导出与导入，支持合并导入与替换导入。
- **屏幕与尺寸自适应**：在手机（窄屏）与平板（宽屏）环境下均能完美自适应，平板自动展现完整七列周历与侧边栏。
