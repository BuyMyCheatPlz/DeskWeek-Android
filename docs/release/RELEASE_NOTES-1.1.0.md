# DeskWeek Android v1.1.0

发布日期：2026-11-10
构建：`versionCode 4` / `versionName 1.1.0`，`minSdk 26`，`targetSdk 36`，`compileSdk 37`
产物：`DeskWeek-1.1.0.apk`，SHA-256 见 [checksums](../release/checksums.txt)

## 相对 1.0.0 新增

**农历 / 节气 / 节日**

- 周视图每一天显示农历日、节气或节日；详情标题带「十月初二」这类信息
- 用 `cn.6tail:lunar`（与桌面版 `vendor/lunar` 同作者、同算法）
- **396 天逐日对照测试**：2026 全年 + 2027 年 1 月，农历月/日/节气/节日与桌面 JS 实现完全一致
- 对照中发现两版对「第 N 个星期几」类公历纪念日（全国助残日、全民国防教育日、世界住房日）处理不同，已在 Android 侧补齐规则并锁定测试

**AI 总结**

- 设置页可配 OpenAI 兼容接口（地址 / 模型 / API Key）
- 粘贴资料 → 「AI 拆解」→ 建议列表 → 「全部添加」入库
- 不配置时整段功能不可用，不影响本地任务
- 5 条单测覆盖请求体、围栏剥离、字段清洗、非 JSON 拒绝
- 本机 mock server 验证真实 HTTP 路径

**配对与信任（P3 切片）**

- 首次连接展示 6 位短认证码（双方公钥排序后 SHA-256 派生），人工核对后写入信任表
- 信任表持久化；**同一 actorId 换公钥会被拒绝**
- 短认证码算法与 JS 侧共 5 条向量，逐字节一致

**后台同步**

- WorkManager 周期任务（最小 15 分钟，系统可推迟），仅在有已配对设备时联网
- 已用 `dumpsys jobscheduler` 确认任务注册（NET 约束、RUNNABLE）

**其它**

- 修复设置页内容变长后底部按钮无法触达的问题（增加滚动）
- 任务支持长按 → 选择目标日期改期

## 已知限制（仍然存在）

- **mDNS 自动发现未实现**：仍是手动填主机/端口
- **拖拽手势未实现**：用「长按 → 选日期」代替，不是跨列拖拽
- **冲突解决 UI 未实现**：冲突只记录在操作日志与投影里，没有界面让用户选择候选值
- **后台同步不保证时效**：Doze、强停、厂商省电策略都会推迟或跳过
- 未在真机与国产 ROM 上验证
- 服务端仍是原型（`scripts/serve-p0.cjs`），没有打包进桌面版安装包
