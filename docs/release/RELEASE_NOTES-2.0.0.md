## ✨ 新增功能

**二维码离线传输**

- 手机和电脑面对面扫二维码就能互传任务，不需要同一网络或联网
- 电脑生成二维码 → 手机扫码导入；手机展示二维码 → 电脑摄像头扫码
- 支持大数据自动分片、乱序扫描、缺片检测、SHA-256 校验
- 导入时可选择合并（保留本机数据）或替换（完全覆盖）

**应用图标**

- 新增与桌面版一致的应用图标，支持 Android 自适应图标（圆形和方形）

## 🛠️ 修复与改进

- **导入安全**：拒绝空 JSON 和重复 ID，无效导入不影响现有数据
- **文件损坏保护**：主文件和备份都损坏时不会丢数据，需要有效导入才能恢复
- **字段兼容**：不认识的字段（比如桌面版新增的）保留不丢
- **编辑冲突**：多处同时编辑时按字段合并，冲突拒绝覆盖
- **小组件**：完整显示任务标题，修改后自动刷新，新增透明模式和文字颜色设置
- **AI 密钥**：改为 Keystore 加密存储，界面不显示明文
- **同步协议**：操作签名验证、组校验、确定性合并（协议层已实现，完整同步功能待后续版本）

## 📝 文档通俗化
