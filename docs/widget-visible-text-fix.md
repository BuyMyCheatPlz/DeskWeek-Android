# 桌面小组件文字与自适应排版优化

在 2.1.1 版本中，针对部分机型和桌面网格下“小组件能看到日期但文字标题被遮挡”的问题，进行了全面的排版与自适应重构。

## 优化要点

1. **智能自适应多尺寸网格**
   - 不再只依据组件宽度判断，而是综合考虑**小组件实际高度、宽度与系统字号缩放比**。
   - 针对常见的“宽而矮”的桌面网格，新增专门的紧凑单行与微型字号布局，确保无论桌面网格如何拉伸，任务标题都能优先保持在第一行完整可见，绝不被挤出视野。

2. **多日期任务智能摘要**
   - 小号与中号组件按「今天事项 → 未排期事项 → 本周其他日期事项」智能呈现。
   - 其他日期的任务会附带直观的月/日标签（如 `11/12 · 整理会议纪要`），一眼看清本周安排。

3. **透明背景与文字颜色即时生效**
   - 修复了在 App 设置中切换“小组件透明背景”或“浅色文字”后，桌面已有的小组件未能即刻更新文字配色的问题。现在切换开关后，桌面小组件文字颜色会瞬间同步响应。

4. **长任务与高度预算管理**
   - 当任务较多且小组件空间有限时，合理计算能放下的行数，放不下的任务会自动显示清晰的“还有 N 项”提示，点击即可打开 App 查看全部。
